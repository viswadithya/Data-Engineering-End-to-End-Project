# Data-Engineering-End-to-End-Project
An end-to-end FMCG Retail Data Engineering project built using Python, PySpark, Apache Spark, Databricks, AWS S3, and Delta Lake. Implements a scalable Medallion Architecture (Bronze, Silver, and Gold) to ingest, process, validate, and transform raw data into analytics-ready datasets. Includes incremental data loading, Change Data Capture (CDC).
